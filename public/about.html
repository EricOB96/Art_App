About MoMA Art Collection Application

Application Overview

The Art Collection application is a web-based platform that allows users to explore, manage, and interact with artworks from the Museum of Modern Art's collection. This application leverages modern web technologies to provide a responsive and user-friendly interface for art enthusiasts, researchers, and casual users alike.

Features Implemented
  • CRUD Operations - Able to add, view, update, delete artwork entries.
  • User authenication - register/login functionality using bcrypt for password hashing and JWT for session management.
  • Personal User Profiles - Able to check profile details as well as add favourite artworks and see them.
  • Search functionality - Find specific artworks as well as filter with artists, Medium and year.
  • Browsing Artworks - Browse through pages of artwork.
  • Responsive Interface - Clean responsive interface that works with smaller screens.
Technologies Used
Backend Technologies:
  • Node.js
  • Express.js
  • MongoDB
  • RESTful API
  • JWT
Frontend Technologies:
  • HTML5
  • CSS3
  • JavaScript (ES6+)
  • Axios
  • Bootstrap 5
Application Weaknesses

While efforts have been made to create a robust application, there are several areas where improvements could be made:

  • Performance Optimization - With many artworks, pagination helps, but better caching and data fetching strategies could improve performance.
  • Error Handling - While basic error handling is implemented, a more comprehensive approach would improve user experience during unexpected errors.
  • Validation - Input validation could be more robust to ensure data consistency.Some Artworks were missing images.
  • Security - Improved security methods to prevent hacking.
  • Accessibility - The application could be improved to better support assistive technologies.
  • Mobile Experience - while the app is still somewhat responsive it could be better to have a dedicated mobile app for better user experience.
Alternative Implementation Approaches

There are several alternative approaches that could be considered for implementing this application:

  • Full-Stack Frameworks - Instead of building separate frontend and backend components, a full-stack framework like Next.js (React) or Nuxt.js (Vue) could provide a more integrated development experience.
  • GraphQL Instead of REST - Using GraphQL could provide more flexibility in querying data and reduce over-fetching or under-fetching of data.
  • Server-side Rendering - Implementing server-side rendering could improve initial load times and SEO (Search Engine Optimization) capabilities.
  • Alternative Databases - While MongoDB works well for this application, a SQL database like PostgreSQL could offer advantages for complex queries and relationships.
  • Containerisation - Docker could make deployment more consistant across environments
