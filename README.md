# Art_App
 Final assignment for EAD

# Instructions

- git clone https://github.com/EricOB96/Art_App.git

- Download Artists.JSON and Artworks.JSON from https://github.com/MuseumofModernArt/collection
- add to root directory of the project

- Install dependencies:       npm install

- start the app:              npm start

- Access the application in browser:    http://localhost:8080
